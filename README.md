# StudentHub

A simple mobile-friendly website for selling student digital services.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Edit `script.js` and replace `919999999999` with your WhatsApp number.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /root → Save**.
5. Your site will get a GitHub Pages URL.

## Important

This starter site does not process payments automatically. For real payments, connect a payment provider such as a supported Indian payment gateway after setting up your merchant account.

Only sell original work/materials that you have the right to distribute. Do not advertise academic cheating or impersonation services.
